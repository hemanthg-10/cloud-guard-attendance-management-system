# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-17

### Added
* Serverless attendance management frontend portal.
* Authentication UI components with Amazon Cognito integration readiness.
* Local mock/demo API functionality via `api.js` replacing previous AWS endpoints for demonstration purposes.
* Student management views by class/section.
* Attendance recording capabilities with Present, Absent, and Late tracking.
* Attendance analytics/dashboard offering visual insights into total students and current attendance rates.
* Dark/Light mode theme toggle.
* Professional repository documentation and structured architecture plans.
